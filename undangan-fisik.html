📋 Petunjuk Cetak & Lipat

① Generate PDF

npm install
node generate-pdf.js

② Setting Printer

  • Kertas: A4 Landscape
  • Skala: 100%
  • Margin: None
  • Duplex: Flip on Short Edge

③ Urutan Cetak

Sisi 1 (Depan)Hal. 1 → Cover Depan (kiri) + Cover Belakang (kanan)
Sisi 2 (Belakang)Hal. 2 → Isi Mempelai+Acara (kiri) + Lokasi+QR (kanan)

④ Cara Lipat

Lipat A4 di tengah vertikal → hasil A5 (148 × 210 mm)

Sisi Luar:                        Setelah lipat & buka:
┌────────────┬────────────┐       ┌────────────┬────────────┐
│ COVER      │ BACK       │       │ MEMPELAI   │ LOKASI     │
│ DEPAN      │ COVER      │       │ + ACARA    │ + QR       │
└────────────┴────────────┘       └────────────┴────────────┘
             ↑ lipat

⑤ Tips

  • Kertas: Art Carton 260gsm
  • Test print 1 lembar dulu di kertas biasa
  • Finishing: laminasi doff + hotprint emas
  • Amplop: C5 (162 × 229 mm)
  • Tulis nama tamu dengan pulpen emas/coklat
