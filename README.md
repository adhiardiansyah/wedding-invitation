# 💍 Wedding Invitation - Adhi & Ayu

Undangan pernikahan digital untuk **Adhi Ardiansyah** & **Adriani Oktaviani Ayu Wangi**.

📅 **Sabtu, 5 September 2026**

## ✨ Fitur

- 🎨 Desain elegan gold & white
- 📱 Fully responsive (mobile-first)
- ⏰ Countdown timer
- 📸 Gallery foto
- 💌 RSVP & ucapan (tersimpan di localStorage)
- 🗺️ Link Google Maps
- ✨ Animasi scroll-reveal
- 🎵 Background music (opsional)

## 🚀 Deploy ke GitHub Pages

1. Push repo ini ke GitHub
2. Buka **Settings** → **Pages**
3. Pilih source: **Deploy from a branch**
4. Branch: **main**, folder: **/ (root)**
5. Akses di: `https://adhiardiansyah.github.io/wedding-invitation/`

## 📸 Menambahkan Foto

Letakkan foto di folder `assets/images/` dengan nama:
- `photo-1.jpg` (foto utama/hero)
- `photo-2.jpg`
- `photo-3.jpg`
- `photo-4.jpg`
- `photo-5.jpg`

## 🎵 Menambahkan Musik

Letakkan file musik di `assets/music.mp3` atau edit tag `<audio>` di `index.html`.

## 📝 Customisasi

Semua data (nama, tanggal, lokasi, cerita) bisa diedit langsung di `index.html`.
